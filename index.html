React v19
Décembre 2024

React 19 — Les nouveautés majeures

React 19 est la mise à jour la plus importante depuis React 18. Elle introduit de nouveaux hooks, améliore la gestion des formulaires et rend les Server Components officiellement stables.

useActionState

Nouveau hook qui simplifie la gestion des états liés aux actions (formulaires, mutations). Il remplace l'ancienne combinaison useReducer + gestion manuelle des erreurs.

useOptimistic

Permet d'afficher une mise à jour "optimiste" de l'UI avant que le serveur confirme l'action — idéal pour les interfaces réactives et les applications temps réel.

Server Components stables

Les React Server Components (RSC) passent en version stable. Ils permettent de rendre des composants côté serveur, réduisant la quantité de JavaScript envoyée au client.

use() — nouveau hook universel

Le hook use() permet de lire des Promises ou des Contexts directement dans le rendu d'un composant, simplifiant la gestion asynchrone.
